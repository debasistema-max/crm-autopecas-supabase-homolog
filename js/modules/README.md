# Modules

Mapa padrao dos modulos do CRM:

- `dashboard`: Inicio;
- `products`: Produtos;
- `customers`: Clientes e cadastros;
- `orders`: Pedidos;
- `quotes`: Cotacoes;
- `imports`: Importacao;
- `users`: Usuarios;
- `settings`: Configuracoes;
- `reports`: Relatorios.

Nesta etapa, os arquivos legados continuam carregados na raiz de `public/js` para preservar ordem global e comportamento. As subpastas sao o destino oficial para migracoes incrementais.
